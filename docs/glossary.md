# Glossary

One name for each thing, everywhere it shows: a panel, the extension that brings it, its Settings section and its tab
carry the same name. Ids (`kelp.git`, `git.changes`, the `git` section) never change; only the shown names do.
Keys are written as macOS writes them: ⌃ ⌥ ⇧ ⌘, never "Ctrl+G". A field's name in a sheet has no colon, as in Settings.

## The window

| Area | English | Russian | Notes |
| --- | --- | --- | --- |
| Left column | Sidebar | Боковая панель | Projects, their chats and agents |
| A folder in the sidebar | Project | Проект | Section header "Projects" / «Проекты» |
| Agents without a project | Chats | Чаты | Its own sidebar row |
| What's on screen for one project | Workspace | Рабочая область | One row in the sidebar, one folder |
| Screen that holds several | Group | Группа | New Group, ⇧⌘N |
| Right column | Inspector | Инспектор | Holds the panels below; Show Inspector, ⌥⌘0 |
| A pane's tabs | Tab | Вкладка | Session, file, diff, page |
| Short message in the corner | Banner | Баннер | Errors and confirmations, never an alert |
| ⌘P | Open Quickly | Быстрое открытие | Files, commands with `>` |
| An empty workspace | Start page | Стартовая страница | Its list: "Open" / «Открыть» |
